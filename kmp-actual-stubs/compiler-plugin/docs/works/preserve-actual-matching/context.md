## User goal and reconciled design review

The target is a child **Cloche common** actual implementing a parent common expect, with an unrelated missing declaration still stubbed in the same compilation. Preserve the actual body and native invalid-actual errors, including when the child is an intermediate fragment in a downstream common compilation. Keep A1–A15, ordinary source types, properties, receiver/parameter overloads, classes/members/enums/typealiases. UNKNOWN causing a legal in-domain declaration to fail is unfinished behavior.

## Semantic and module ownership

- [Registrar](../../../src/main/kotlin/net/msrandom/stub/StubCompilerPlugin.kt) owns invocation-local registration, existing options and KSP service discovery.
- [FIR transformer](../../../src/main/kotlin/net/msrandom/stub/fir/FirExpectTransformer.kt) now converts top-level callables only on proven absence, preserving potential actual matches for native checking. P3 must establish equivalent whole-class/enum/member decisions; incomplete empty buckets cannot prove absence.
- Native callable matching distinguishes receiver, parameter types/count, generics/substitution/bounds, owner and graph before later compatibility. P2 compares nonempty overloads with compiler matching semantics and retains bound incompatibility for native diagnostics. A complete empty candidate bucket proves callable absence; UNKNOWN is never absence. A concrete in-domain failing UNKNOWN would reopen P2.
- [Enum generator](../../../src/main/kotlin/net/msrandom/stub/fir/FirExpectEnumConstructorGenerator.kt) can be queried in SUPERTYPES before STATUS. It and the [IR generator](../../../src/main/kotlin/net/msrandom/stub/ir/IrStubBodyGenerator.kt) must share the proven class decision. Retained enums get no stub constructor; retained actual bodies get no generated stub markings.
The historical P1/P2-era obligations below were discharged for the accepted fixture in P3. `FirExpectTransformer.kt` keeps retained class constructors and members native as a unit; missing class/enum constructors, functions and accessors receive generated throwing bodies. Enum pre-STATUS choice shares the class decision; matched enum constructors are not replaced. Native typealias expansion retains Target and member/constructor incompatibility errors. The 38 P3 named variants and full controls are indexed in the [P3 report](../../../../../../jvm-multiplatform-actual-matching/kmp-actual-stubs/compiler-plugin/build/p3-declaration-coverage/report.zh-CN.md); do not treat these fixed-version controls as proof for arbitrary future source extensions.
